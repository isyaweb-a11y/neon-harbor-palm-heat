Neon Harbor: Palm Heat — an original open-world crime game for the browser. Explore a sun-soaked harbor city on foot and by car: traffic and pedestrians, cars to steal and drive, a wanted level with police who respond, a five-mission story, combat, side activities, a HUD with a minimap, synthesized sound and music, a start screen, and saving. All static files under `game/`, no build step, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
